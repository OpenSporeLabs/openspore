### Cross-cutting facts

- Mode strategies (`cCellModeStrategy`, `cCreatureModeStrategy`, `cScenarioMode`) are
  vtable-dispatched with no static callers (dossier "Callers" section) — stage entry is
  via `cGameModeManager::SetActiveModeAt` (`0x007d8d40`, decompiled).
- Singletons are global pointers: e.g. `Simulator::cSimulatorSystem::Get` returns
  `DAT_0167eaf0`; `Simulator::Cell::sCellGame` at `0x16b3c04` (VERIFIED addresses).
- All 3,081 vtable candidates scanned `.rdata/.data` (778k words); 369 high-confidence;
  306 associated with SDK classes — the class-hierarchy workhorse absent from RTTI.

## 4. Selected first target + why

**Recommendation: Cell stage completion** — promote the existing slice
(`src/sim/` + `src/apps/cell_stage.cpp` + `src/replace/`) from approximated stand-in
scene to a real, playable cell stage with genuine assets and decompiled-faithful
steering.

Evidence:

1. **Head start is unique in the repo**: deterministic sim (Obj 17a), real-asset scene
   (Obj 16), lit renderer (Obj 15), the *only* `replaced-approx` subsystem with a
   64/64 differential match (`docs/REPLACEMENT-DIFF.md`), frozen contract + fixtures
   (`docs/CELL-CONTRACT.md`, `tests/fixtures/cell/`), and the in-process hook mechanism
   proven on native 32-bit (`tools/replace/synthetic/`). No other subsystem has any
   implementation.
2. **Knowledge completeness is highest**: `docs/analysis/dossiers/cell-movement.md`
   (ray-plane steering OBSERVED in decompilation; all vtable-dispatch facts),
   26 decompiled Cell functions, `Simulator/Cell/` SDK headers (13 files),
   asset-resolver type/group tables (`tools/spore/types/`), 4,209 dumped GMDL records.
3. **Its remaining gates are decode-side, not runtime-gated**:
   - world-object record `0x0f43029a` (1,022 records confirmed present, undecoded —
     `docs/STATE.md` §5) → scene placement + player-cell identity
     (`docs/ASSET-IMPORT-ROADMAP.md` manifest-driven path);
   - ray-plane constants `DAT_015a7c40/44/48` + `DAT_016b3c28/2c/30` — values can be
     *read from the static binary* (`.rdata`), no trace needed to pin the plane;
   - cell animation arrives via target #4 (Anim/RW4).
   The S5 runtime trace (gated, human-watched) is only needed to *promote* status to
   `replaced-verified`, not to build the stage.
4. **Downstream**: the mode-strategy + camera + input patterns established here are
   reused verbatim by creature/space stages (same `IGameMode` vtable shape, dossier
   evidence).

Sequence inside target: (1) read plane constants from static binary → promote from
APPROXIMATION; (2) port ray-plane steering into CellSim (contract test already exists);
(3) decode `0x0f43029a` world-objects → real scene placement + player-cell identity;
(4) RW4 keyframe animation of the cell (with target #4); (5) S5 trace when approved
to promote `replaced-approx` → `replaced-verified`.

Final selection (subagents 5/6, 2026-09-23): confirmed — Cell stage, 32 targets in
5 waves (`docs/analysis/campaigns/cell-stage-campaign.md`). Executed the same day:
all 5 waves done (31 DONE / CS-32 PARTIAL trace-gated). Key corrections found
during execution: original cell placement is *procedural* (populate records carry
zOffset/distribution; no stored x/y table); worldobj `0x0f43029a` is a distinct
model-group format (magic `0xABB455B7`), not CellSerializer-based; 1,365 records
(1,022 base + 343 EP1); clear color (0,90,152) is sampled from the backgroundMap
ramp, not hardcoded.

## 5. Known blockers (per subsystem, then overall)

Per-subsystem (the ones that matter for the top-5 targets):

- **Cell**: (a) world-obj `0x0f43029a` record format undecoded; (b) player-cell
  record identity unresolved (no name↔instance map in assets —
  `docs/STATE.md` §5, `docs/ASSET-IMPORT-ROADMAP.md`); (c) S5 cell-mode runtime trace
  (gated, human-watched) for status promotion.
- **Asset pipeline**: (a) RW4 container C++ walker (python oracle
  `tools/spore/rw4.py` exists — pure port); (b) PNG32 `0x2f4e681b` = RW4, no decoder
  (1,131 records in Spore_Content); (c) `.prop` property record round-trip unproven;
  (d) GMDL v9 layout undecoded (0 of 4,209 records observed — may be ignorable).
- **App core**: menu-transition trace (tracer exists; `menu_transition.json` probes
  defined but never run — headless menu nav impossible, `docs/STATE.md` §5).
- **Anim**: anim-manager internals are unnamed `FUN_*` (only 1 named Anim function
  binary-wide); TLSA/anim_cid binary formats need first-pass decode; no runtime.
- **UTFWin**: message-dispatch semantics at status `hypothesis` — needs a
  menu-transition trace; no OpenSpore UI foundation exists yet.
- **Terrain**: heightfield decode oracle exists; weather state manager undecoded.
- **Space/Civ**: no gameplay traces; scenario data formats undecoded.
- **Audio/Pollinator**: no observed call sequences; Pollinator service defunct → stub.
