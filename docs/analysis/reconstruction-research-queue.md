# Reconstruction Research Queue

## Queue semantics

The pinned readiness artifact contains 368 rows: 365 canonical functions and 3 non-canonical records. It is a reconstruction worklist, not the full 2,149-function gameplay population. `LIKELY_INFRASTRUCTURE` means characterize or stub only; it is not a semantic implementation target.

All contracts remain `unknown`. The source rank is preserved when present; otherwise rows are in deterministic VA order. Package candidates are inference labels unless explicitly anchored in Track O.

The queue is not the unresolved gameplay backlog. The 1,598 `unknown-needs-investigation` gameplay rows, 1,976 semantic-not-established rows, and 1,977 rows without a persisted body are different, potentially overlapping populations with different denominators:
